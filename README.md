# Сайт-приглашение на свидание 💌

Адаптивный сайт на HTML, CSS и JavaScript. Для запуска не нужны сборка и сервер; его можно опубликовать через GitHub Pages.

## Файлы

- `index.html` — экраны приглашения, выбора плана, бонус-вопроса и ответа.
- `style.css` — оформление, стеклянная карточка, запотевшее стекло на первом экране и анимации.
- `script.js` — видеофон, протирание запотевшего стекла мышью или пальцем, эффекты, бонус с пиксельным раскрытием фото, форма и отправка/копирование ответа.
- `peach-and-goma.gif` — котик, который выглядывает у правого края первого экрана и бросает лепестки; на узких экранах он появляется внизу справа.

Фото для бонуса — `bonus.jpg`. Его можно заменить своей фотографией, сохранив это имя.

## Добавить видеофон

Положи ролики рядом с `index.html` и назови исходники:

- `background-landscape.mp4` — горизонтальное видео для компьютера.
- `background-portrait.mp4` — вертикальное видео для телефона.

Сайт выбирает ролик по ориентации окна и переключает его при повороте устройства. Для плавного цикла «вперёд — назад» рядом с исходниками используются подготовленные файлы `background-landscape-pingpong.mp4` и `background-portrait-pingpong.mp4`. Если подготовленной версии нет или браузер не может её загрузить, сайт попробует оригинал, затем видео другой ориентации. Если ни один ролик недоступен, останется градиентный фон. Видео запускается без звука.

## Публикация через GitHub Pages

Загрузи `index.html`, `style.css`, `script.js`, `bonus.jpg`, `peach-and-goma.gif`, оба исходных видео и оба файла `*-pingpong.mp4` в корень репозитория. В GitHub открой **Settings → Pages**, выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохрани настройки. Адрес сайта появится там же.

Telegram открывает список чатов с подготовленным текстом; ответ отправляется только после выбора чата и подтверждения. Если сайт опубликован не по HTTPS или буфер обмена недоступен, кнопка копирования использует запасной способ.

Лепестки, бабочки, сердечки, котик и шлейф блёсток отключаются при системной настройке уменьшения анимации. Сайт не собирает и не сохраняет ответы на сервере.
